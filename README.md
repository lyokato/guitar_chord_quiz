# ギター練習ツール

ギター練習補助ツール集。単一の `index.html` で完結(ビルド不要・サーバー不要)。

- 公開URL: https://lyokato.github.io/guitar_practice/
- **コードクイズ** — コードポジションを反射的に思い出す訓練クイズ
- **リズムボックス** — ドラムパターン付きメトロノーム(練習曲の伴奏用)
- **練習用プレイヤー** — 端末内の曲を速度変更・区間ループして反復練習

## コードクイズの使い方

1. **スタート** でクイズ開始。コード情報が大きく表示され、カウントダウン後に答えの指板が表示される
2. ナビゲーションライン: カウンタ、⏸一時停止 / ▶再開、右端の「進む」ボタン(回答待ち→答えを表示 / 回答表示→次の問題)
3. 指板右上の音符ボタンで、そのボイシングの音を再生できる
4. **コンフィグ** で以下を調整:
   - タイマー: 問題→答えの秒数 / 答え→次の秒数(自動送りOFFで手動進行)
   - 指板表示: 度数(R, 3, ♭7...)⇔ 音名
   - レッスン用一括設定: Phase 1〜11 のボタンで教室のレッスン内容に合わせたフィルターを一発適用
   - 出題フィルター: コードタイプ×構成の二段リスト、ローコード・オンコードの個別選択、ルートの弦(6弦 / 5弦 / 5弦左展開)と音(♯・♭の呼び名込み17種)
5. 設定はブラウザの localStorage に自動保存される(端末ごと)

## リズムボックスの使い方

1. リズムパターンを選ぶ(クリック / 8ビート / 16ビート / 4つ打ち / シャッフル / 3/4)
2. BPMスライダーでテンポを指定(40〜240)
3. フィルインの頻度を選ぶ(なし / 2・4・8小節ごと)。フィル後の小節頭にはクラッシュが入る
4. 再生ボタンでスタート。拍のインジケーターが点灯する。設定は再生中でも変更可能

ドラム音はWeb Audioでの合成(サンプルファイル不使用)。iPhoneは消音スイッチONでも再生される。

## 練習用プレイヤーの使い方

1. **ファイルを選択**から端末内の音声・動画ファイルを開く(1曲20MB以下)
2. 白いつまみをタップまたはドラッグして、練習したい再生位置へ移動する
3. オレンジ色の**A**と**B**をドラッグしてループ範囲を決める。A–B間は最低3秒で、AがBを追い越すことはない(3秒未満の曲は曲全体)
4. コントロール行で、範囲のリセット、Aへの移動、再生/一時停止、0.50〜1.50倍の速度選択を行う
5. 最近使った5曲は**最近の曲**から再度開ける。A/Bと再生速度も曲ごとに復元される

選択した曲はサーバーへ送信せず、ブラウザ内のIndexedDBにコピーして保存する。これはiPhone・Android・PCで共通して履歴を再利用するためで、元ファイルのパスは保存しない。ブラウザのサイトデータを消去した場合、プライベートブラウズを終了した場合、OSが保存領域を整理した場合は履歴も消える可能性がある。

## スマホのホーム画面に追加(PWA)

- iPhone: Safariで開き、共有ボタン →「ホーム画面に追加」
- Android: Chromeのメニュー →「ホーム画面に追加」(または表示されるインストール提案)

以後はホームのアイコンから全画面(ブラウザUIなし)で起動する。PCブラウザでの利用は従来通り。
注意: iOSのホーム画面版はSafari本体と設定・最近の曲(localStorage / IndexedDB)が別管理になる。
一度オンラインで開けば、以後は圏外でもオフライン起動できる(Service Workerによるキャッシュ)。
