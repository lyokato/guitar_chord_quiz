# ギターコード・ポジションクイズ

ギターのコードポジションを反射的に思い出すための訓練アプリ。出題されたコード情報(例: 「6弦ルート / 2・3・4弦」+「F# m7」)から指板上のポジションを頭に浮かべ、数秒後に表示される答え(指板グラフィック+サウンド)で確認する。

- 公開URL: https://lyokato.github.io/guitar_chord_quiz/
- 単一の `index.html` で完結(ビルド不要・サーバー不要)

## 使い方

1. **START** でクイズ開始。コード情報が大きく表示され、カウントダウン後に答えの指板が表示される
2. ナビゲーションライン: カウンタ、⏸一時停止 / ▶再開、右端の「進む」ボタン(回答待ち→答えを表示 / 回答表示→次の問題)
3. 指板右上の音符ボタンで、そのボイシングの音を再生できる
4. **SETTINGS** で以下を調整:
   - タイマー: 問題→答えの秒数 / 答え→次の秒数(自動送りOFFで手動進行)
   - 指板表示: 度数(R, 3, ♭7...)⇔ 音名
   - レッスン用一括設定: Phase 1〜11 のボタンで教室のレッスン内容に合わせたフィルターを一発適用
   - 出題フィルター: コードタイプ×構成の二段リスト、ローコード・オンコードの個別選択、ルートの弦(6弦 / 5弦 / 5弦左展開)と音(♯・♭の呼び名込み17種)
5. 設定はブラウザの localStorage に自動保存される(端末ごと)
