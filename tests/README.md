# ピッチ変更の回帰検証

```sh
node --test tests/*.test.mjs
```

外部パッケージ不要。実際のAudioWorkletProcessorをNode.js上で、ブラウザと同じ
128サンプル単位（可変サイズ試験では64／256も使用）で実行する。

## 修正対象

旧処理は2048サンプルのFFTで解析し、合成先の同じビンへ移った複数成分の
周波数を音量で加重平均していた。そのため、設定された半音数が一定でも、
重なった音の強弱に応じて出力周波数が動く。また左右の位相を独立にゼロから
合成していたため、入力のステレオ位相関係も失われていた。

修正後は8192サンプルで近いピークを分離し、ピークのフレーム間位相差から
実周波数を推定する。ピークの周辺領域を同じ周波数差・位相補正で移動し、
重なる出力は複素スペクトルとして加算する。左右には共通の領域・補正を使う。
位相は毎フレーム±πへ折り返し、長時間の積算で巨大な値にならないようにする。

方式の背景: [Laroche / Dolson, New phase-vocoder techniques for real-time
pitch-shifting, chorusing, harmonizing and other exotic audio modifications](https://www.ece.uvic.ca/~peterd/48409/Dobson1999.pdf)。
既存のFFTを改修した実装で、第三者のコードや実行時依存は追加していない。

FFTを4段階に分け、通常の128サンプルのレンダーコールバックに1回ずつ分散する。
テーブル・バッファは起動時に確保し、レンダー中は配列やビューを生成しない。
遅延は8192+512=8704サンプルで、カウントインはこの報告値を補正に使う。

## 試験範囲

- 44.1kHz／48kHz、82.4・110・220・440Hz、−3〜+3半音の全候補。
  音量を変調し、100msの窓を10msずつ動かして一時的なずれを測る。
  許容値は6セント（半音=100セント）。全区間の平均だけでは判定しない。
- 220Hzと246.94Hzの同時音。強弱を入れ替え、各音のスペクトルピークを個別に測る。
  和音へゼロクロスの単音推定器を適用しない。
- ステレオ逆相の和音、モノラルの定位、0半音での波形再構成。
- ±3半音をそれぞれ180秒固定した連続再生と、位相値の上限。
- シーク後の新規プロセッサーとの一致、入力切断時の残響排出、連続キー変更。
- 再生経路の並行初期化、最新設定の適用、0半音のバイパス、初期化／実行時エラー、
  AudioContextの再開、読み込み中の曲変更。

合成音の試験は報告された実音源の完全な再現ではない。実機確認では、同じ曲・
同じ開始位置・速度1.0倍・固定キーで、症状の出た区間を含めて再生する。
ブラウザ／端末、キー、曲内時刻、再生を始めてからの経過時間を記録すると、
入力内容に依存する変換誤差と、端末の負荷や再生経路の問題を区別しやすい。
